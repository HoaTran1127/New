# T5-12 — Percentage Lab

Build a standalone single-file HTML Grade 5 mathematics game.

Learning goal: connect percentages with hundred-grids, fractions and decimals and solve simple percentage-of-quantity problems.

Player mission: operate a visual laboratory by converting and solving percentage challenges.

Gameplay: start with visual 100-cell grids, then progress to fraction/decimal/percentage matching and practical percentage-of-quantity questions. Use familiar values such as 10%, 20%, 25%, 50% and 75%, then introduce other suitable values.

Input: optional webcam pointing/selection using MediaPipe Hands with calibration, smoothing, confidence threshold 0.65 and 300ms cooldown. Mouse, touch and keyboard fallback is mandatory.

Create at least 50 tagged questions. Randomize option order. Include misconception traps such as treating percent as a whole number, confusing tenths with hundredths and reversing a conversion.

Feedback must show the hundred-grid, conversion and calculation step by step.

Include mastery by skill, missed-question recycling, reduced motion, camera-off mode and a clear privacy notice. Do not upload camera frames.

Return one complete HTML file with all data embedded and no TODOs.
