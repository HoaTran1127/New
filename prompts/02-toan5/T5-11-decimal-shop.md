# T5-11 — Decimal Shop

Create a standalone single-file Grade 5 Math game.

Learning objective: read, compare, order, add and subtract decimals in realistic money/measurement contexts.

Mission: complete customer orders by selecting the exact decimal amount.

Gameplay: customers provide prices, weights or distances. The player assembles the requested decimal using place-value cards or chooses the correct result.

Camera: optional fingertip POINT/DRAG using MediaPipe Hands, smoothing, confidence >= 0.65, explicit drag state and 300ms drop cooldown. Mouse/touch fallback.

Create 50 questions covering decimal place value, comparison, addition and subtraction. Include traps for misplaced decimal points, trailing-zero confusion and reversed comparisons.

After every answer show a place-value alignment and one-line calculation. Recycle missed concepts.

Use a 12-question round, progress meter and end-of-round mastery by skill. Camera optional and no upload. Output one complete HTML file with inline code and no TODOs.
