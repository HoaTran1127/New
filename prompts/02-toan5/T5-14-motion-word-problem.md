# T5-14 — Motion Word-Problem Racer

Create a standalone single-file Grade 5 Math game.

Learning objective: solve elementary motion problems using distance, speed and time relationships appropriate to the curriculum.

Mission: choose the correct route, speed, time or distance to keep a delivery vehicle on schedule.

Gameplay: each race gives a short word problem. The player extracts known quantities, selects the needed operation/formula, then answers. Include diagrams and a timeline rather than text-only problems.

Control: POINT for route selection; optional gesture/keyboard controls. Webcam must not be required.

Generate at least 36 problems with varied contexts and one-step/two-step difficulty. Include traps from mixing units, using the wrong quantity and ignoring elapsed time.

Feedback shows known → unknown → relationship → calculation → answer with units.

Use accessible reading, optional text-to-speech, no camera upload. Output one complete HTML file with all data embedded and no TODOs.
