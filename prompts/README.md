## 🗂️ Danh Mục Prompt Có Sẵn

1. **[00 - Master Canvas System Prompt](00-master-canvas-prompt.md):** Khung sườn kỹ thuật ép Gemini tuân thủ chuẩn 1 file HTML, MediaPipe mượt, Tone.js không lỗi.
2. **[01 - Subway Math Blitz AR](01-prompt-subway-math-blitz.md):** Prompt tái tạo chính xác tựa game trong link bạn đã gửi (Chém thẻ rơi, né thẻ sai, kính vỡ).
3. **[02 - AR Math Catcher](02-prompt-math-catcher-ar.md):** Prompt tạo game hứng quả táo/vật phẩm toán học.
4. **[03 - Math Ninja Bubble Pop](03-prompt-ninja-bubble-pop.md):** Prompt tạo game chém bong bóng số thập phân (Fruit Ninja style).
5. **[Mẫu Điền Nhanh Game Mới (Template)](template-tao-game-moi.md):** Biểu mẫu để bạn điền ý tưởng mới vào là có ngay prompt hoàn chỉnh.

---

## 🚀 3 Bước Tạo Game Bằng Gemini Canvas

1. Mở [Google Gemini](https://gemini.google.com).
2. Mở file Prompt bạn muốn (ví dụ: `01-prompt-subway-math-blitz.md`), copy toàn bộ nội dung và dán vào khung chat của Gemini.
3. Gemini sẽ tự động mở giao diện **Canvas** bên phải màn hình và viết toàn bộ mã nguồn game. Bạn chỉ việc bấm nút **"Run / Chạy thử"** hoặc copy file HTML về đưa vào repo này!
