Chỉ hiển thị mục có đường dẫn file thật. Không có file thì không có card.

MiTi • prompt thật • một file HTML độc lập • chữ ký thương hiệu
Nguồn dữ liệu: lưới card này được sinh từ catalogs/GAME_CATALOG.csv và tools/data/ qua node tools/build.mjs → catalogs/GAME_CATALOG.js. Không sửa tay file JS và không thêm card thủ công: muốn đổi nội dung game thì sửa tools/data/games.mjs, muốn đổi nội dung giáo án thì sửa tools/data/lessons.mjs, rồi build lại. Nút Sao chép prompt tải file .md và chỉ lấy khối text, phần ghi chú dành cho người tạo không bị chép theo.
