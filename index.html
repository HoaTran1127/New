Chỉ hiển thị mục có đường dẫn prompt. Không có file thật thì không có card.

MiTi • prompt thật • HTML game độc lập • chữ ký thương hiệu
Nguồn dữ liệu: lưới game này được sinh từ catalogs/GAME_CATALOG.csv qua node tools/build.mjs → catalogs/GAME_CATALOG.js. Không sửa tay file JS và không thêm card thủ công: muốn đổi nội dung thì sửa tools/data/games.mjs rồi build lại.
